# Проект Banking transactions widget

## Описание:

Проект Banking transactions widget - это серверная часть виджета банковских операций. Виджет показывает несколько последних успешных банковских операций клиента.

## Установка:

1. Клонируйте репозиторий:
```commandline
git clone https://github.com/evgenios33/banking_transactions_widget.git
```
2. Установите зависимости:
```commandline
pip install -r requirements.txt
```

## Использование:

На данном этапе в проекте реализованы функции позволяющие определять тип банковского продукта (карта или счет) и маскировать номер банковской карты или счета, функция возвращающая дату в формате "ДД.ММ.ГГГГ", а также функции фильтрации банковских операций по статусу и сортировки по дате.

Примеры работы функций:

1. Функции возвращающие маску номера карты или счета.
- get_mask_card_number
```commandline
7000792289606361     # входной аргумент
7000 79** **** 6361  # выход функции
```
- get_mask_account
```commandline
73654108430135874305  # входной аргумент
**4305  # выход функции
```
2. Функция, которая определяет и возвращает тип банковского продукта с замаскированным номером.
- mask_account_card
```commandline
# Пример для карты
Visa Platinum 7000792289606361  # входной аргумент
Visa Platinum 7000 79** **** 6361  # выход функции

# Пример для счета
Счет 73654108430135874305  # входной аргумент
Счет **4305  # выход функции
```
3. Функция возвращающая дату в формате "ДД.ММ.ГГГГ".
- get_date
```commandline
2024-03-11T02:26:18.671407  # входной аргумент
11.03.2024  # выход функции
```
4. Функции фильтрации по статусу операции и сортировки по дате.
- filter_by_state
```commandline
# входные данные
[{'id': 41428829, 'state': 'EXECUTED', 'date': '2019-07-03T18:35:29.512364'}, 
{'id': 939719570, 'state': 'EXECUTED', 'date': '2018-06-30T02:08:58.425572'}, 
{'id': 594226727, 'state': 'CANCELED', 'date': '2018-09-12T21:27:25.241689'}, 
{'id': 615064591, 'state': 'CANCELED', 'date': '2018-10-14T08:21:33.419441'}]

# выход функции со статусом по умолчанию 'EXECUTED'
[{'id': 414288290, 'state': 'EXECUTED', 'date': '2019-07-03T18:35:29.512364'}, 
 {'id': 939719570, 'state': 'EXECUTED', 'date': '2018-06-30T02:08:58.425572'}]

# выход функции, если вторым аргументом передано 'CANCELED'
[{'id': 594226727, 'state': 'CANCELED', 'date': '2018-09-12T21:27:25.241689'}, 
 {'id': 615064591, 'state': 'CANCELED', 'date': '2018-10-14T08:21:33.419441'}]
```
- sort_by_date
```commandline
# входные данные
[{'id': 41428829, 'state': 'EXECUTED', 'date': '2019-07-03T18:35:29.512364'}, 
{'id': 939719570, 'state': 'EXECUTED', 'date': '2018-06-30T02:08:58.425572'}, 
{'id': 594226727, 'state': 'CANCELED', 'date': '2018-09-12T21:27:25.241689'}, 
{'id': 615064591, 'state': 'CANCELED', 'date': '2018-10-14T08:21:33.419441'}]

# выход функции (сортировка по убыванию, т. е. сначала самые последние операции)
[{'id': 41428829, 'state': 'EXECUTED', 'date': '2019-07-03T18:35:29.512364'}, 
{'id': 615064591, 'state': 'CANCELED', 'date': '2018-10-14T08:21:33.419441'}, 
{'id': 594226727, 'state': 'CANCELED', 'date': '2018-09-12T21:27:25.241689'}, 
{'id': 939719570, 'state': 'EXECUTED', 'date': '2018-06-30T02:08:58.425572'}]
```
