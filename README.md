# Проект Banking transactions widget

## Описание:

Проект Banking transactions widget - это серверная часть виджета банковских операций. Виджет показывает несколько последних успешных банковских операций клиента.

## Установка:

1. Клонируйте репозиторий:
```commandline
git clone https://github.com/evgenios33/banking_transactions_widget.git
```
2. Установите зависимости:
```commandline
pip install -r requirements.txt
```

## Использование:

На данном этапе в проекте реализованы функции позволяющие определять тип банковского продукта (карта или счет) и маскировать номер банковской карты или счета, функция возвращающая дату в формате "ДД.ММ.ГГГГ", а также функции фильтрации банковских операций по статусу и сортировки по дате. 

Добавлен модуль generators.py в котором реализованы: функция фильтрации банковских операций по заданной валюте, функция-генератор возвращающая описания операций и генератор номеров банковских карт в заданном диапазоне.

Добавлен модуль decorators.py в котором реализован декоратор @log, который логирует имя функции, время выполнения и результат при успешном выполнении, и информацию об исключении и переданных аргументах в случае ошибки. Выводит информацию в консоль или записывает в файл, если он указан в аргументе filename.

### Примеры работы функций:

#### 1. Функции возвращающие маску номера карты или счета.
- get_mask_card_number
```commandline
7000792289606361     # входной аргумент
7000 79** **** 6361  # выход функции
```
- get_mask_account
```commandline
73654108430135874305  # входной аргумент
**4305  # выход функции
```
#### 2. Функция, которая определяет и возвращает тип банковского продукта с замаскированным номером.
- mask_account_card
```commandline
# Пример для карты
Visa Platinum 7000792289606361  # входной аргумент
Visa Platinum 7000 79** **** 6361  # выход функции

# Пример для счета
Счет 73654108430135874305  # входной аргумент
Счет **4305  # выход функции
```
#### 3. Функция возвращающая дату в формате "ДД.ММ.ГГГГ".
- get_date

## Тестирование:

Для тестирования проекта используется библиотека `pytest`. Все основные функции покрыты тестами, чтобы обеспечить корректность работы программы.

### Запуск тестов
Запуск тестов осуществляется командой:
```
pytest tests/
```




### Покрытие тестами
Код проекта покрыт тестами более чем на 80%, что позволяет уверенно говорить о его надежности.

### Отчеты покрытия
HTML-отчеты по покрытию тестами можно найти в папке `htmlcov` после выполнения команды:
```
pytest --cov=.
```
