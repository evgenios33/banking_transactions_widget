# Проект Banking transactions widget

## Описание:
Проект Banking transactions widget - это серверная часть виджета банковских операций. Позволяет читать из JSON, CSV, XLSX, фильтровать по статусу/валюте, сортировать по дате, искать по описанию и безопасно маскировать реквизиты.

## Возможности:
- **Поддержка нескольких форматов данных**: JSON, CSV, XLSX.
- **Гибкая фильтрация**:
  - по статусу операции (`EXECUTED`, `CANCELED`, `PENDING`);
  - по валюте (в том числе отдельная фильтрация по RUB);
  - по подстроке в описании транзакции.
- **Сортировка по дате**: по возрастанию или убыванию.
- **Безопасное отображение данных**: автоматическое маскирование номеров карт и счетов (оставляются первые 6 и последние 4 цифры для карт, последние 4 — для счетов).
- **Устойчивость к некорректным данным**: обработка `NaN`, отсутствующих полей, ошибок парсинга дат без падения программы.
- **Интерактивный CLI-интерфейс**: пошаговое меню с валидацией ввода пользователя.

## Установка и запуск:

### Установка
**1. Клонируйте репозиторий:**
```commandline
git clone https://github.com/evgenios33/banking_transactions_widget.git
```
**2. Установите зависимости:**
```commandline
pip install -r requirements.txt
```

### Подготовка данных
**Положите файлы транзакций в папку `data/` в корне проекта:**
- `operations.json`
- `transactions.csv`
- `transactions_excel.xlsx`

Формат файлов должен соответствовать ожидаемой структуре (список словарей с полями `date`, `description`, `from`, `to`, `amount`, `currency_name` и т.д. для CSV- и XLSX-файлов или `date`, `description`, `from`, `to`, `operationAmount`, `amount`, `currency`, `name` и т.д. для JSON).

### Запуск
```commandline
python main.py
```
После запуска откроется интерактивное меню, где можно выбрать источник данных и задать условия фильтрации.

## Пример работы
1. Пользователь выбирает источник данных (например, CSV).
2. Указывается статус операции (например, EXECUTED).
3. Выбирается сортировка по дате (по убыванию).
4. При необходимости включается фильтрация только по рублёвым операциям.
5. Можно дополнительно отфильтровать по слову в описании (например, «счет»).
6. На выходе — отсортированный и отфильтрованный список транзакций с замаскированными реквизитами и суммами.

**Пример вывода одной операции:**
```commandline
01.01.2026 Перевод с карты на счет
Visa Classic 7022 98** **** 6865 -> Счет **3410
Сумма: 33249.01 руб.
```

## Обработка ошибок и устойчивость
- При отсутствии файла выводится понятное сообщение (не исключение в консоль).
- Если дата не может быть распарсена, выводится только описание операции.
- Некорректный ввод в меню обрабатывается повторным запросом без завершения программы.

## Разработка и расширение
**Проект спроектирован с учётом модульности:**
- Логика чтения данных вынесена в `src/data_readers`.
- Фильтры и сортировка — в `src/processing`.
- Форматирование и маскирование — в `src/widget`.

Это позволяет легко добавлять новые типы фильтров, источники данных или форматы вывода.

## Тестирование:
Для тестирования проекта используется библиотека `pytest`. Все основные функции покрыты тестами, чтобы обеспечить корректность работы программы.

### Запуск тестов
**Запуск тестов осуществляется командой:**
```
pytest tests/
```

### Покрытие тестами
Код проекта покрыт тестами более чем на 80%, что позволяет уверенно говорить о его надежности.

### Отчеты покрытия
HTML-отчеты по покрытию тестами можно найти в папке `htmlcov` после выполнения команды:
```
pytest --cov=src --cov-report=html
```
